## 노트북 쓰는 법

목차 페이지의 **Colab에서 열기** 를 누르면 설치 없이 바로 실행된다.
내려받아 로컬 Jupyter 에서 열어도 된다. `numpy` · `matplotlib` · `scipy` 만 있으면 돌아간다.

```python
import numpy as np
rng = np.random.default_rng(20260302)   # 모든 노트북이 이 시드를 쓴다
```

시드를 고정해 두었으므로 **여러분 화면의 숫자가 강의 슬라이드와 같아야 한다.**
다르면 시드를 바꿨거나 셀을 두 번 실행한 것이다.
