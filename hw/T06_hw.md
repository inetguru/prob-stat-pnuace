## 문제 1. Pareto 분포 샘플러 (10점)

**Pareto 분포**는 "소득 상위 20%가 부의 80%를 갖는다"는 파레토 법칙의 그 분포다.
웹 트래픽, 도시 인구, 파일 크기처럼 **꼬리가 두꺼운** 현상에 쓰인다.

$$F_X(x) = 1 - \left(\frac{x_m}{x}\right)^{\alpha} \quad (x \ge x_m)$$

- **(a)** $F_X$ 를 뒤집어 $x = F^{-1}(u)$ 를 **손으로 유도**한다 (마크다운에 과정을 적을 것)
- **(b)** `rng.random()` 만 써서 샘플러를 구현한다 ($x_m = 1$, $\alpha = 2$)
- **(c)** 표본 20만 개의 히스토그램과 이론 PDF $f_X(x) = \alpha x_m^\alpha / x^{\alpha+1}$ 를 겹쳐 그린다
  (x축을 0~10 정도로 잘라야 보인다)
- **(d)** `scipy.stats.pareto(b=2)` 와 비교해 두 히스토그램이 겹치는지 확인한다

## 문제 2. 꼬리의 무게 (8점)

같은 평균을 갖도록 Exponential과 Pareto를 맞춰놓고 비교한다.

- **(a)** $\alpha = 2, x_m = 1$ 인 Pareto의 이론 평균을 구한다 ($\mathbb{E}[X] = \alpha x_m/(\alpha-1)$)
- **(b)** 같은 평균을 갖는 Exponential의 $\lambda$ 를 정한다
- **(c)** 두 분포에서 각각 20만 개를 뽑아 다음을 표로 비교한다
  - 평균 / 중앙값 / 99 퍼센타일 / 최댓값
- **(d)** **평균은 같은데 최댓값이 왜 이렇게 다른가?** 3문장으로 설명한다

## 문제 3. 언제 평균이 무의미해지는가 (7점)

- **(a)** $\alpha$ 를 1.2, 2.0, 3.0 으로 바꿔가며 각각 표본 10만 개의 **누적 평균 그래프**를 그린다
- **(b)** 어느 $\alpha$ 에서 누적 평균이 잘 안정되지 않는가?
- **(c)** Pareto는 $\alpha \le 1$ 이면 기댓값이 **존재하지 않는다.**
  랩에서 본 Cauchy와 어떤 점이 같고 어떤 점이 다른지 3문장으로 쓴다
