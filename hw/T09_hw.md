## 문제 1. 나만의 "같은 통계량, 다른 그림" 만들기 (10점)

평균·표준편차·상관계수가 **모두 같은데 그림은 전혀 다른** 데이터셋 **3개**를 만든다.

- **(a)** 세 데이터를 생성한다. 다음 함수를 쓰면 통계량을 맞출 수 있다.

```python
def normalize(x, y):
    """평균 0, 표준편차 1, 상관 0 으로 맞춘다."""
    x = (x - x.mean()) / x.std()
    y = (y - y.mean()) / y.std()
    r = np.corrcoef(x, y)[0, 1]
    y = y - r * x
    y = (y - y.mean()) / y.std()
    return x, y
```

- **(b)** 세 데이터의 평균·표준편차·상관계수를 **표로 출력**해 같음을 보인다
- **(c)** 세 산점도를 나란히 그린다
- **(d)** 이 실험이 주는 교훈을 2문장으로 쓴다

> 💡 아이디어: 하트 모양, 글자 모양, 두 개의 직선, 나선, 격자…
> 수식으로 만들기 어렵다면 **점을 손으로 몇십 개 찍어 배열로 적어도 된다.**
