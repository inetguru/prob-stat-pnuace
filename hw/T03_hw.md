## 개요

**무작위성이 있는 게임(또는 뽑기) 하나를 골라** 확률 모형으로 기술하고,
기댓값과 분산을 계산한 뒤 시뮬레이션으로 검증한다.

### 주제 예시 (직접 골라도 된다)

| 주제 | 확률변수 $X$ 의 예 |
|---|---|
| 모바일 게임 가챠 | 10연차에서 얻는 ★5 개수 |
| 아이템 강화 | 목표 단계까지 필요한 시도 횟수 |
| 로또 / 복권 | 1장당 순수익 |
| 사다리타기·주사위 보드게임 | 특정 칸 도달 여부, 이동 거리 |
| 자판기 랜덤 상품 | 원하는 상품을 얻기까지의 비용 |

> ⚠️ 실제 게임의 공시 확률을 쓸 경우 **출처를 명시**할 것. 없으면 가정을 직접 세우고 명시한다.

## 문제

### 1. 모형 세우기 (5점)

- 게임 규칙을 3~5줄로 서술한다
- **확률변수 $X$ 가 무엇인지 한 문장으로 정의**한다 (예: "$X$ = 한 판의 순수익, 단위 원")
- **PMF를 표로** 제시한다. $\sum_x p_X(x) = 1$ 임을 확인할 것

### 2. 손으로 계산 (8점)

- $\mathbb{E}[X]$ 를 정의대로 계산한다. **계산 과정을 마크다운에 적을 것** (숫자만 적으면 감점)
- $\mathbb{E}[X^2]$ 를 구하고 $\mathrm{Var}[X] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$ 로 분산을 구한다
- 표준편차 $\sigma_X$ 까지 구한다

### 3. 시뮬레이션 검증 (7점)

- **10만 회** 시뮬레이션한다 (`rng = np.random.default_rng(20260302)`)
- 표본평균·표본분산을 이론값과 표로 비교한다
- **누적 평균이 $\mathbb{E}[X]$ 로 수렴하는 그래프**를 그린다 (x축 로그 스케일 권장)

### 4. 해석 (5점)

다음 세 가지를 각각 2~3문장으로.

- **(a)** 이 게임은 참가자에게 유리한가 불리한가? 근거는 무엇인가?
- **(b)** $\sigma_X$ 를 근거로, **몇 판쯤 해야** 표본평균을 믿을 수 있을지 논한다.
  (정확한 답은 Topic 10에 배운다. 여기서는 그래프를 근거로 한 관찰이면 충분하다)
- **(c)** 기댓값만 보고 판단하면 위험한 이유를 이 게임의 예로 설명한다

## 자주 하는 실수

- $\mathbb{E}[X^2]$ 를 $(\mathbb{E}[X])^2$ 로 계산 → **LOTUS를 쓸 것**
- 시뮬레이션 표본분산과 이론 분산이 안 맞을 때: `np.var(x)` 는 $n$ 으로 나눈다.
  표본분산 $n-1$ 로 나누려면 `np.var(x, ddof=1)`. **이 차이는 Topic 12에서 다룬다**
