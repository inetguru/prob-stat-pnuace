## E. 코드 읽기 (시험에 이런 형식이 나온다)

**E1.** 다음 코드가 추정하는 값은 무엇인가? 이론값은 얼마인가?

```python
rng = np.random.default_rng(20260302)
x = rng.integers(1, 7, size=(100000, 2))
print((x.sum(axis=1) == 7).mean())
```

**E2.** 다음 코드의 출력이 0.5에 가까워지지 **않는** 이유는?

```python
c = np.tan(np.pi * (rng.random(1000000) - 0.5))
print(np.cumsum(c)[-1] / 1000000)
```

**E3.** 다음 코드는 무엇을 검증하려는 것인가?

```python
x = -np.log(1 - rng.random(200000)) / 0.7
print((x > 3).mean() / (x > 2).mean(), np.exp(-0.7))
```

## 시험 준비 요령

- **공식을 외우기보다 "언제 쓰는가"를 정리할 것.** 분포표와 $z$-표는 제공된다
- 매주 랩 노트북의 **마지막 마크다운 셀(한 문장 요약)** 을 다시 읽어보면 좋다
- 계산 실수를 줄이려면 **단위와 조건(독립인가? 복원인가?)** 을 먼저 확인하는 습관
- 코드 읽기 문제는 **작성**을 요구하지 않는다. "무엇을 시뮬레이션하는가"만 답하면 된다
