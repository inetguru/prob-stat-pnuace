L1 · L2 정규화 — prior가 벌점이 되는 이유

확률통계 · Topic 13 보충자료 — 슬라이드 20번 "MAP — posterior의 최빈값" · 32번 "→AI 연결점 — L2 정규화 = Gaussian prior"

슬라이드에서 본 것 MAP을 최소화 꼴로 쓰면 벌점 항이 −log p(θ) 라는 것. 그리고 "L2 정규화 = Gaussian prior, L1은 Laplace prior"라는 한 줄.
이 노트가 답하는 것 L1·L2의 L은 무엇인가. 벌점이 왜 prior에서 나오는가. L1은 왜 가중치를 정확히 0으로 만들고 L2는 그러지 않는가.
어디서 이어지는가 Topic 7 Laplace 분포 · Topic 12 과적합과 NLL · Topic 13 MAP과 prior의 세기. 다차원 회귀와 최적화 이론은 심화 주제다.

1. L은 무엇인가 — 크기를 재는 여러 방법

L은 프랑스 수학자 Henri Lebesgue(앙리 르베그)의 머리글자다. 그가 정리한 함수 공간 Lp 에서 이름이 왔다. L1·L2는 벡터 w = (w1, …, wd) 의 "크기"(노름, norm)를 재는 두 가지 방법이다.

‖w‖p = ( |w1|p + |w2|p + ⋯ + |wd|p )1/p
p = 1 이면 L1, p = 2 이면 L2 노름
정의별명w = (3, 4)
L1|w1| + |w2| + ⋯맨해튼 거리 — 격자 길을 따라 걷기7
L2√(w1² + w2² + ⋯)유클리드 거리 — 직선 거리5
L4(w1⁴ + w2⁴ + ⋯)1/4p가 커질수록 가장 큰 성분에 가까워진다4.285

직접 해보기 — 크기가 1인 점들은 어떤 모양일까

‖w‖p = 1 인 점을 모두 그린 것이 단위 공(unit ball)이다. p = 2 이면 원, p = 1 이면 모서리가 축 위에 있는 마름모가 된다. 이 모서리가 4절의 주인공이다.

2. 정규화 — 손실에 벌점을 더한다

머신러닝은 손실을 최소화해서 가중치를 정한다. 데이터에만 맞추면 가중치가 과하게 커져 훈련 데이터에만 잘 맞는 과적합이 생긴다 (Topic 12 →AI). 그래서 가중치의 크기에 벌점을 붙인다.

최소화할 것 = 손실(데이터에 안 맞는 정도) + λ × 벌점(가중치의 크기)
λ(람다)가 클수록 벌점이 세다 — 가중치를 0 쪽으로 더 세게 당긴다
L2 정규화 벌점 = w1² + w2² + ⋯ (L2 노름의 제곱)
다른 이름 — Ridge, 신경망에서는 weight decay
L1 정규화 벌점 = |w1| + |w2| + ⋯ (L1 노름)
다른 이름 — Lasso

3. 벌점은 어디서 오는가 — prior의 −log

슬라이드 20의 MAP 식을 다시 보자. 최대화를 최소화로 바꾸려면 부호를 뒤집는다.

θ̂MAP = argmax [ log p(x | θ) + log p(θ) ] = argmin [ −log p(x | θ) + (−log p(θ)) ]
파란 부분이 손실(NLL, Topic 12), 주황 부분이 벌점이다. 벌점 = −log prior

"가중치는 0 근처일 것 같다"는 prior를 두 가지 모양으로 써 보면:

prior밀도−log p(w)정규화
Gaussian N(0, τ²)∝ e−w²/(2τ²) — 0에서 둥근 봉우리 w² / (2τ²) + 상수L2, λ = 1/(2τ²)
Laplace(0, b)∝ e−|w|/b — 0에서 뾰족한 봉우리 |w| / b + 상수L1, λ = 1/b
prior의 세기 = 정규화의 세기. prior가 좁을수록(τ, b가 작을수록) λ가 커진다. 슬라이드 7에서 본 "강한 prior는 데이터를 이기려면 더 많은 데이터가 필요하다"가 머신러닝에서는 "λ를 크게 잡으면 가중치가 데이터를 덜 따른다"가 된다. 상수는 argmin 위치를 바꾸지 않으니 버려도 된다 — 슬라이드 20에서 evidence를 버린 것과 같은 이유다.

4. 왜 L1은 정확히 0을 만드는가

가중치가 하나일 때 — 공식으로 보기

가장 단순한 경우를 보자. 데이터만 보면 가중치가 m 이 되는 상황에서 (손실 = (w − m)²/2), 벌점을 더한 최소점은 손으로 풀린다.

최소화할 것최소점 w*성질
L2(w − m)²/2 + λ·w²/2m / (1 + λ)λ가 커져도 0에 다가갈 뿐 닿지 않는다
L1(w − m)²/2 + λ·|w|m − λ (단, λ ≥ m 이면 정확히 0)λ가 m 을 넘는 순간 0에 붙는다
# m = 1.5 일 때 (손으로도 확인할 수 있다)
m = 1.5
for lam in [0, 0.5, 1, 1.5, 2]:
    print(lam, "L2", m / (1 + lam), "L1", max(m - lam, 0))
0   L2 1.5   L1 1.5
0.5 L2 1.0   L1 1.0
1   L2 0.75  L1 0.5
1.5 L2 0.6   L1 0.0
2   L2 0.5   L1 0

L1 의 공식을 soft thresholding(부드러운 문턱)이라 부른다. 작은 가중치는 통째로 0이 된다. Laplace prior의 봉우리가 0에서 뾰족하기 때문이다. Gaussian은 0에서 둥글어서, 0 근처로 당기기는 해도 정확히 0에 세우지는 못한다.

직접 해보기 — λ를 키우면 가중치가 어떻게 줄어드나

L2 — m/(1+λ)L1 — max(m−λ, 0)

가중치가 둘일 때 — 그림으로 보기

벌점을 더하는 것은 "가중치의 크기를 t 이하로 제한하고 손실을 최소화하는 것"과 같다 (λ와 t가 일대일로 대응한다). 그러면 답은 손실의 등고선(타원)이 단위 공을 처음 건드리는 점이다. L1 공은 마름모라서 모서리가 먼저 닿기 쉽다. 모서리는 축 위에 있고, 축 위에서는 한 가중치가 0이다.

직접 해보기 — 등고선이 어디에 먼저 닿는가

L2 공 (원)과 그 답L1 공 (마름모)과 그 답손실 등고선
그래서 L1은 특징 선택을 한다. 가중치가 수천 개일 때 L1 정규화를 쓰면 쓸모없는 특징의 가중치가 정확히 0이 되어 모델에서 빠진다(sparsity, 희소성). L2는 모든 가중치를 골고루 조금씩 줄여 모델을 부드럽게 만든다. 둘을 섞은 것을 Elastic net이라 부른다.
