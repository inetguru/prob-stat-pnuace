훈련 오차와 실제 오차 — 모델은 왜 새 데이터에서 더 못할까

확률통계 · Topic 10 보충자료 — 슬라이드 23번 "Hoeffding 부등식" · 32번 "오늘 배운 것이 AI의 어디에 있나"

슬라이드에서 본 것 Hoeffding 부등식이 머신러닝에서 "훈련 오차와 실제 오차가 얼마나 다를 수 있나"를 따질 때 쓰인다는 한 문장. 그리고 "훈련 데이터의 평균 손실로 진짜 손실을 대신해도 되는 이유는 LLN"이라는 말.
이 노트가 답하는 것 두 오차가 각각 무엇인지, 둘이 왜, 얼마나 다른지. 차이의 원인은 두 가지다 — 우연(표본이 유한하다)과 선택(데이터를 보고 모델을 골랐다).
어디서 이어지는가 Topic 3 손실함수와 Risk · Topic 1 train/test 나누기 · Topic 12 MLE · Topic 14 다중검정. 일반화 이론(generalization bound)은 심화 주제다.

1. 두 오차는 무엇인가 — "세 개의 평균"과 같은 구조

분류 모델 h 하나가 있다. 데이터 한 개 (x, y)를 넣어서 틀리면 1, 맞히면 0을 적는다 (0-1 손실). 이 0과 1의 평균을 어디서 내느냐에 따라 오차의 이름이 갈린다.

실제 오차 (true error, risk)   R(h) = P[ h(X) ≠ Y ] = E[손실]
세상에서 앞으로 들어올 모든 데이터에서 틀릴 확률 — 모평균 μ 에 해당한다.

훈련 오차 (training error, 경험적 위험)   R̂ₙ(h) = (1/n) · Σ 손실ᵢ
가진 데이터 n 개에서 틀린 비율 — 표본평균에 해당한다.

Topic 3 보충자료 손실함수와 Risk에서 "기계학습은 손실의 기댓값(Risk)을 줄이는 일"이라고 했다. 그 Risk가 실제 오차다. 그런데 기댓값은 계산할 수 없으니, 학습은 늘 훈련 오차를 대신 줄인다 (경험적 위험 최소화, ERM). 이 대체가 정당한지가 이 노트의 질문이다.

2. 모델이 하나뿐이라면 — 차이는 "우연"뿐이다

데이터를 보기 전에 모델이 이미 정해져 있다고 하자. 그러면 각 데이터에서의 손실은 실제 오차 p를 확률로 하는 Bernoulli(p)이고, 데이터가 IID라면 손실들도 IID다. 훈련 오차는 그냥 동전 던지기의 표본평균이 된다.

  • LLN — n이 커지면 훈련 오차는 실제 오차로 간다. ERM이 말이 되는 이유다.
  • 치우침이 없다 — E[훈련 오차] = p. 좋게 나올 때도, 나쁘게 나올 때도 있다.
  • 흔들림의 크기 — 표준편차 √(p(1−p)/n). n = 100, p = 0.3 이면 약 0.046.
  • Hoeffding — 손실이 0 아니면 1이라 [0, 1] 조건을 자동으로 만족한다. 분포를 전혀 몰라도 아래처럼 말할 수 있다.
P[ |훈련 오차 − 실제 오차| ≥ ε ] ≤ 2·exp(−2nε²)
95% 확신으로 말할 수 있는 폭은 ε = √( ln(2/0.05) / (2n) ) — n = 100 이면 ±0.136, n = 1,000 이면 ±0.043. (Chebyshev·Hoeffding은 분포를 몰라도 되는 대신 느슨하다 — 실제 흔들림은 이보다 훨씬 작다.)

🔬 시뮬레이션 ① — 모델 하나, 훈련 데이터 1,000세트

실제 오차가 p인 모델 하나를 고정해 두고, 크기 n인 훈련 데이터를 1,000번 새로 뽑아 훈련 오차를 1,000개 모은다. 히스토그램이 p를 중심으로 좌우 대칭이고, n을 키우면 좁아지는 것을 확인한다. 초록 띠가 Hoeffding의 95% 폭이다.

3. 데이터를 보고 모델을 고르면 — 차이에 "선택"이 더해진다

실제 학습은 모델을 하나만 쓰지 않는다. 수많은 후보(가중치 조합) 중에서 바로 이 훈련 데이터에서 오차가 가장 작은 것을 고른다. 이 순간 2절의 계산이 깨진다.

⚠️ 극단적인 사고 실험. 후보 모델 100개가 있는데 전부 실제 오차가 30%로 똑같이 좋다고 하자. 훈련 데이터 100개에서 각각의 훈련 오차를 재면 운에 따라 22%, 35%, 27% … 로 흩어진다. 그중 가장 작은 것을 고르면 그 모델의 훈련 오차는 평균 약 19%다. 그런데 그 모델의 실제 오차는 여전히 30%다. 고른 것은 "좋은 모델"이 아니라 "운이 좋았던 모델"이다.

Topic 10의 도박사의 오류(슬라이드 14)를 떠올리면 된다. 동전 100개를 각각 100번 던져서 앞면이 가장 적게 나온 동전을 골라도, 그 동전이 다음에도 앞면이 적게 나오지는 않는다. 과거의 운은 이어지지 않는다. 이 체계적인 낙관을 선택 편향(selection bias)이라 부르고, 훈련 데이터에서만 좋은 이 현상이 과적합(overfitting)의 확률적인 뿌리다.

🔬 시뮬레이션 ② — 똑같이 좋은 후보 M 개 중에서 "최고"를 고른다

실제 오차는 모든 후보가 0.300. 표의 값은 이항분포로 계산한 기댓값이다.

표에서 읽을 것 ① 후보가 많을수록(모델이 복잡할수록) 편향이 커진다. 다만 M 이 10배가 될 때 편향은 훨씬 느리게 는다 — 대략 √(ln M) 에 비례한다.
표에서 읽을 것 ② 데이터가 많을수록 편향이 줄어든다 — 대략 1/√n 에 비례한다. 오늘 배운 표준오차의 그 √n 이다. "복잡한 모델일수록 데이터가 더 필요하다"는 말의 정량적 근거다.

4. 극단 — 외워 버리는 모델

후보가 사실상 무한히 많으면 어떻게 될까. 가장 극단적인 모델은 훈련 데이터를 통째로 외우는 표다. "이 이메일이면 스팸, 저 이메일이면 정상"을 1,000통 모두 적어 두고, 처음 보는 메일은 동전을 던져 정한다.

훈련 오차실제(테스트) 오차
외우는 모델0%약 50% — 동전 던지기
단순한 규칙 ("무료", "당첨"이 있으면 스팸)8%9% 안팎

아래 행은 설명용으로 든 가상의 수치다.

훈련 오차만 보면 외우는 모델이 완벽하다. 하지만 그 0%는 아무것도 말해 주지 않는다. 반대로 단순한 규칙은 훈련 오차와 실제 오차가 거의 같다 — 후보가 적어서 선택 편향이 작기 때문이다.

5. 그래서 데이터를 나눈다 — 세 번째 오차, 테스트 오차

계산에 쓴 데이터실제 오차와의 관계무엇에 쓰나
훈련 오차모델을 고르는 데 쓴 데이터우연 + 선택 → 낙관적으로 치우친다학습(ERM)
검증 오차여러 모델·설정 중 하나를 고르는 데 쓴 데이터후보가 적어 편향은 작지만 0은 아니다모델 선택
테스트 오차모든 선택이 끝난 뒤 처음 보는 데이터우연만 남는다 → 치우침 없음최종 성능 보고

테스트 데이터는 선택에 관여하지 않았으므로, 그 시점의 모델은 2절처럼 "미리 정해진 모델 하나"다. 그래서 테스트 오차에는 Hoeffding과 표준오차 √(p(1−p)/n)을 그대로 쓸 수 있다. 테스트 1,000개로 정확도 92%를 얻었다면 "실제 정확도는 대략 92% ± 1.7%(표준오차 2개)"라고 말할 수 있다. 데이터를 나누는 구체적인 방법은 Topic 1 보충자료 데이터를 나눈다는 것에 있다.

⚠️ 테스트 데이터를 여러 번 보면 그것도 훈련 데이터가 된다. 테스트 점수를 보고 모델을 고치고, 다시 테스트하고, 또 고치면 — 테스트 데이터로 모델을 고르고 있는 것이다. 3절의 선택 편향이 그대로 되살아난다. 공개 리더보드 경진대회에서 순위가 최종 비공개 평가에서 크게 뒤집히는 일이 흔한 이유가 이것이다.

한 줄 요약 — 실제 오차는 모평균처럼 알고 싶지만 모르는 값이고, 훈련 오차는 가진 데이터로 계산한 표본평균이다. 둘은 우연 때문에 조금 다르고(Hoeffding이 잰다), 훈련 데이터로 모델을 골랐기 때문에 훈련 오차가 더 좋아 보이도록 치우친다. 그래서 실제 오차는 따로 떼어 둔 테스트 데이터로 추정한다.
